# Direct-stack geometry candidate (ST-02)

Authority: **PROPOSAL (planning)**. Status: **generated planning candidate; unvalidated draft; not adopted**. Every result here is a courtyard-and-pad-level screen. None is a copper clearance, a tolerance result or a physical fit.

This folder replaces the ad hoc measurements behind [the direct board-stack plan](../../../doc/src/content/docs/decisions/osc-direct-stack-plan.mdx) with a generated candidate and a retained checker.

| File | What it is | Owner |
| --- | --- | --- |
| `stack-candidate.json` | Planes, 203 rigid pairs with sites, envelopes and pin maps, 18 posts, four P tabs, SUB toggle windows, EL relief holes and pot passages, the fixing list with coordinates, retired items, input hashes and the canonical input digest | Generated by `scripts/stack/geometry/generate.py` |
| `check-report.json` | Checker verdict, per-check detail and the reconciliation measurements | Generated by `scripts/stack/geometry/check.py` |
| `land-pattern.json` | **The single connector land-pattern input** (schema 2): per half (`K` = TW-SM stacker, `front` = socket) and per row count, a rule with status and source, plus optional explicit `<rows>x<per row>` entries. The stacker halves are DERIVED from the TW-SM footprint revision C; the socket halves are PROVISIONAL | Hand-edited input |
| `parameters.json` | Planning parameters (schema 2): adapter mated height (sets K's plane), enclosure depth cases, row counts, pin-order templates, removed carriers, relief holes, pot passage diameter, stacker rule, fixings and tie sites, adapter standoff keep-out | Hand-edited input |

```sh
python3 scripts/stack/geometry/generate.py      # writes stack-candidate.json
python3 scripts/stack/geometry/check.py         # writes check-report.json; exit 1 on any error
python3 scripts/checks/frozen_studies.py discover scripts/stack/geometry   # 50 tests, about 28 s
```

After editing `land-pattern.json` or `parameters.json`, or after any board, partition or lock change, run both commands again. A parameter-only change needs no code change. No KiCad and no network are needed.

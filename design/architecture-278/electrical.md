## Load accounting

`device_coverage` covers every source-ledger package once, retaining units, DNP, existing board, proposed O1 owner, decoupling association, mapped IC supply pins and rail classes. `worksheet_loads` retains each whole-instrument worksheet row and its source/conditions once. It is deliberately a separate accounting view: never sum it with per-device coverage. All seven per-device complete state maxima remain null. An unmatched resistor, capacitor, diode, connector or transistor is **unmapped**, not a zero load. A fitted IC with no supplied rail is **unserved**. DNP excludes fitted demand only. **Partial** means a worksheet allowance exists; **supported** would require a complete bounded load and currently has zero entries. Empty rails for non-IC rows mean the historical physical-IC ledger does not map that device; it does not mean electrically disconnected. Passive load extraction/operating-point attribution is still needed before acceptance. The data exposes this incompleteness rather than distributing lumped reserves arbitrarily across front and rear.

O1 planning allowances are +12 V 62.7 mA, -12 V 61.8 mA and +5 V 6 mA. One shared octave source adds 26/26/0 mA once. Thus one zone including the entire shared service is 88.7/87.8/6 mA; adjacent O1/O2 is 151.4/149.6/12 mA; all five is 339.5/335/30 mA. These totals include worksheet reserves, not fault maxima. The shared-reference reserve contains the REF5050 load; it must not be added again simply because that package has no exact named worksheet row. AS3340 VEE current is charged through its local -12 V-powered VEE5 buffer, not a second fictional supply. Whole-instrument source ceilings in the historical rail budget remain design targets, not measured capacity. Other functions remain boundary-level inventory.

The source sheet reports 3300 nF nominal startup capacitance per OSC and 700 nF for the shared source, without enough rail/owner/tolerance partition to allocate inrush safely. Use C dV/dt for each actual rail, add leakage and ESR/ESL, and charge common source contributions once. Keep each package bypass with its supply unit and local return; inspect `decouples_ref` and the complete interface pins. Added middle/front/rear bulk needs an explicit rail/polarity/voltage/ESR/tolerance inventory. It cannot silently replace local bypass or consume unallocated source protection capacity.

## Whole-path model and inherited requirements

The proposed source-to-load envelope is source output → source/middle cable → middle zone → keyed interface/link → load owner, followed by the corresponding complete return to source. Front-jack, front-control, rear-core and shared-reference branches fork at the middle zone; the model does **not** require powering the rear through the front. Each segment includes its complete wire, PCB trace/via/spreading resistance and **both** endpoint mating interfaces/crimps where present. A continuity drawing is not a resistance bound. Common edges carry the sum of downstream loads once; each path uses the common prefix and exactly one branch tail. The conservative full-zone current used below is an envelope, not a claim that every edge carries the same current.

`topology_comparison` records separate branch owners for the preferred and limited-change alternatives. Core-only retains existing JL/JR/P interfaces and adds a removable-core link; preferred separates front jack/control boards and connects each to the middle. Both use identical common-prefix plus branch-tail resistance ceilings. Exact contact counts and routes remain null pending connector and support decisions, so neither topology receives invented resistance savings. The eventual graph must include shared-reference current only once, include every final connector face, and replace this bounded envelope with branch-specific values before implementation acceptance.

| Unchanged requirement | Proposed combined allocation | Remaining evidence |
| --- | --- | --- |
| Branch plus K common ground ≤0.5 mΩ | Four return segments ×0.125 mΩ | Measured/extracted worst-case complete segments, shared return current and temperature |
| Combined rail transfer ≤1 mΩ | Four rail segments ×0.25 mΩ | Connector/crimp/wire/trace/ageing and load topology |
| Hot distribution ≤20 mV | I downstream × complete rail path | Dynamic peak and contact sharing bounds |
| Full source/rail/return ≤0.20 V | Source regulation + hot loss + return shift + transient droop | Source regulation/protection and every state, no budget reset at middle PCB |
| GH ≤0.5 A per contact | Compare each actual contact current; never assume equal parallel sharing | Exact connector topology, contact imbalance and thermal derating |

These resistance allocations are aspirations and may prove infeasible with removable links. No connector is claimed to meet a 0.125 or 0.25 mΩ segment. Unknown actual resistance stays null. Source impedance has no invented allocation. Existing resistance failures are not waived. With all-five planning loads, allocated 1 mΩ gives 0.3395/0.335/0.030 mV hot loss. The intentionally conservative sum of rail current magnitudes is 704.5 mA, giving 0.35225 mV at 0.5 mΩ. A single GH return contact would exceed 0.5 A under that envelope; cancellation of positive/negative currents is not a safe fault-state credit. These tiny hypothetical drops cannot establish the 0.20 V requirement because source and dynamic errors remain unknown.

For each future actual path calculate Rwire = ρ(T)L/A, Rtrace = ρ(T)L/(wt) plus vias/spreading and contact/crimp maxima; ΔVhot = Σ Iedge Redge; ΔVreturn uses actual return directions and a conservative worst-state envelope. Include L dI/dt and capacitor droop ΔI Δt/C plus ESR ΔI. Missing dimensions, material/temperature, waveform, component maxima or topology make the result OPEN. Nearby continuous return copper follows every OSC zone crossing. Logical zones must not create ground slits, narrow return bottlenecks or a common audio/CV bus.

## References, controls and five receivers

The shared octave source is retained for comparison. Independent references would introduce separate calibration/drift evidence and are not assumed. Proposed per selected octave net capacitance allocation is shared trace 50 pF + shared test fixture 50 pF + five branches × (cable 80 + contacts 10 + trace 30 + receiver 20 + probe/test 20 pF) = **900 pF**, leaving 100 pF aggregate margin. Each of the six octave tap nets must meet this envelope across all switch states, including switch/connector parasitics. The allocation is not an extracted capacitance. It bounds direct interconnect/parasitic capacitance only: the existing selected-tap receiver has 100 nF behind 1 kΩ, which is not represented by the 20 pF receiver parasitic allocation. The frequency-dependent admittance and switched recharge of all five RC receivers require a separate transient/settling/stability and source-current analysis; the 900 pF sum does not pass that check. One prototype needs five-receiver-equivalent loading; a one-branch 1 nF test would violate the shared condition. Local remote control complete paths retain ≤300 mm and ≤1000 pF including connectors, traces and test equipment. No cable pF/m has been invented to declare a length acceptable.

Proposed worst-case absolute per-receiver error allocation is contact 100 µV, remote return 200 µV, loading 200 µV, drift 200 µV, peak noise 100 µV, source/buffer offset 200 µV: total **1000 µV**. Two adjacent receiver errors could differ by 2000 µV, leaving no margin against the 2 mV adjacent-step target. Correlation and actual transfer need review; bandwidth, temperature span and ageing interval are OPEN. DC error terms are Iload Rcontact, Ibias Zsource, gain/offset and remote AGND shift; drift is TC × ΔT plus ageing, noise is evaluated over a defined bandwidth with a reviewed peak convention. A local buffer leaves remote-ground error intact. Every actual term is unknown, so this budget is not passed. Five-cents tracking at 25 °C is a separate target and is not inferred from this allocation.

The existing conditional fanout report is retained with its exact local output/load rows, 100 Ω isolation, 100 Ω feedback, 1 nF compensation and 2 mA driver planning limit. Those values are historical powered-operation conditions, not new placement or stability authority. Feedback remains local. The eight controls retain their interface classifications: five unbuffered pots and three mechanical selectors. Nominal Rpot/4 is not a tolerance bound: a 100 kΩ pot with +20% resistance reaches 30 kΩ before source/contact impedance; 1 nF then yields 30 µs as a simple pole estimate only. Source drive, switch transitions, receiver nonlinearities, capacitance and settling still need qualification. No buffer is presumed for a wiper.

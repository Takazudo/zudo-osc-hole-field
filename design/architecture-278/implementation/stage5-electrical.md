## Proposed acceptance targets for review

These targets are **PROPOSAL, NOT APPROVED**, and no actual pass is reported. Allocate20% of the retained five-cent whole-chain target to collective pitch interconnect error: one cent, or0.833333mV input-referred at1V/oct. This is shared across simultaneous paths, not a fresh allowance per wire. The remaining four cents/3.333333mV must cover the core, calibration, reference and amplifier terms outside the driver-pad-to-receiver-pad interconnect boundary; sufficiency is unknown. Retain200µV as the proposed return suballocation and leave633.333µV for other interconnect errors. Apply actual summing gains before combining contributions and avoid counting source/amplifier error twice. The352µV return example already misses that suballocation.

For modulation, propose that added interconnect changes complex gain by no more than1% relative to the captured, position-dependent intentional RC transfer where the baseline exceeds10% of its DC gain. Below that floor, report absolute output error. This is a review proposal for added transfer error, not a manufacturer bound or an audibility claim. It does not demand flat20kHz response from the intentionally filtered TUNE/FINE/PW networks, and cannot be evaluated without the required driver/passive models.

For conditioned gate transport, propose zero false and zero missed SYNC_GATE edges over100 pulses per declared0/5V grid case, one rising and one falling transition per input pulse with a fixed selected SYNC state. Use only edge-time/pulse-width combinations satisfying edge time≤10% of the pulse width, measured between50% crossings. This finite diagnostic criterion does not establish statistical reliability or promise a minimum supported pulse width. HARD/SOFT core synchronization is observed separately across phase/frequency states; no universal lock criterion is invented without the receiver model and an agreed operating envelope.

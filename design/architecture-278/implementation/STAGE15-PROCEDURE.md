## What is physically available

Existing OFFSET can set a reachable baseline while an independent meter observes OUT with IN=CV=0. This is real front-control positioning, not an added trim. Choose ATTEN first, then set OFFSET, because changing ATTEN can also change the intercept. ATTEN selects the IN contribution. Neither front control independently adjusts external-CV gain `gr*gcv`; no stored correction or factory-only gain actuator is present.

A temporary zero/baseline setup can absorb constant offset at that operating point. It cannot remove CV slope error, voltage-dependent input/protection/amplifier errors, drift or load change. After moving OFFSET the old baseline is intentionally lost; after moving ATTEN the IN gain and possibly baseline change. Meter-setting a new offset is normal intended operation. Factory verification at one setting does not guarantee absolute zero at every later knob position. Modelled CV gain is independent of both control fractions, but physical invariance must be verified across settings and conditions.

## Concrete proposed procedure — unadopted, NOT RUN

The following is a proposal for factory screening and temporary operating-point setup. It is not an implemented factory calibration and does not certify that the hardware can meet the target.

1. **Fixture and conditions.** Record DUT revision, actual rails and reference voltage, source/receiver grounds, source impedance, meter loading and uncertainty. Use independently calibrated external sources and meter, observing input voltages at their jack and output at OUT_TIP. Warm up20minutes per canonical standard. Propose25°C initial characterization and a measured10kohm static load; these conditions and the service envelope require protocol approval. Only unclipped, verified linear headroom is eligible for accuracy acceptance.
2. **Real baseline setup.** Set IN=CV=0 and record ATTEN at centre. Declare `Btarget=0V` before measuring; turn existing OFFSET while observing the meter. Record actual achieved error, resolution and uncertainty. If unreachable, record setup failure. Freeze both controls. Do not redefine Btarget to the measured output or store a correction coefficient.
3. **External-CV transfer.** Apply measured CV−5,−2.5,0,+2.5,+5V in both directions at fixed IN=0, controls and10k load, including zero readings before/after. Evaluate raw `OUT−(Btarget+CVmeasured)` against the unchanged2mV target with uncertainty accounted for. Separately report paired slope, intercept, incremental transfer and curvature/repeat-zero drift. Pair subtraction cancels a stable intercept diagnostically; it is not physical calibration or absolute acceptance. No adjustment within the sweep.
4. **Stability after adjustment.** Without rezeroing, hold CV=0 and record output at0,1,5,15,30minutes, then repeat±5V CV. Report both drift and absolute deviation from the declared baseline. This proposed finite window does not establish lifetime or temperature performance; no new drift tolerance is invented. Static results still use2mV at the tested conditions, with the shared error budget below.
5. **Movement and manual characterization.** Traverse OFFSET centre/endpoints and return from both directions; record actual range, centre output, approach-dependent repeatability, settling and drift without comparing knob markings to a prescribed voltage tolerance. Then physically establish selected Btarget−2,0,+2V and repeat CV sweeps for ATTEN fractions0,.5,1, resetting the baseline after ATTEN changes. These are measured operating targets, not knob-position requirements. B±5 requires verified±7V linear headroom in the nonzero-baseline cases; otherwise those cases are NOT RUN, not silently passed or extrapolated. Recheck CV gain to test its physical invariance after control motion.
6. **IN-path verification.** Keep CV=0. Select desired IN gain−1,0,+1 where reachable using source/meter, then set manual baseline0 and hold both controls. Sweep IN−5,0,+5V against `Btarget+Gdesired*INmeasured`. Unreachable desired gain is a specific IN adjustment gap, not evidence of external-CV failure. No IN-path criterion is relaxed. Its gain setting is not retained after ATTEN movement.
7. **Distinct load change.** Establish nominal−5,0,+5V output states with declared inputs/controls, then alternate documented instrument-open and10kohm loads without changing inputs, either control, calibration state or reference conditions. Evaluate `OUT10k−OUTopen` against1mV. Record settling and instrument loading; never rezero between loads. This difference is separate from the2mV absolute static test.
8. **Disposition and persistence.** Repeat the declared baseline/gain checks after control movement and power cycling as characterization. Report each lane and condition as pass/fail/NOT RUN; no aggregate factory acceptance until the procedure, uncertainty rule and environmental coverage are approved. Power/temperature persistence cannot be inferred from one successful setting.

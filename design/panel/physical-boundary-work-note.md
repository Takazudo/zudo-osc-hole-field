# Panel physical-boundary verification

The original issue #37 checker validated the 438 feature footprints and only the outline bounding box. A pinned KiCad 10.0.6 disposable probe on main `a6e0dc8581e6d4f0b96550ce94163b02313ced04` reproduced false passes after separately adding a 0.3 mm via drill, adding an internal 2 mm Edge.Cuts circle, and changing board thickness to 1.6 mm. All three still printed “no extra features”; the canonical source board stayed unchanged. Initial guarded attempts were NOT RUN (canceled before updating main; contention exit 75); the completed probe took 8 seconds. Local logs and board copies remain ignored.

The bounded correction reads the panel source dimensions, radius and thickness and checks the actual native physical boundary. Width and height must still match the fixed lockfile frame. Every segment and arc, including stroke, layer and native midpoint geometry, must match the source rounded rectangle; Edge.Cuts inside footprint graphics are included. Added drilled vias are rejected. Signed distance to the rounded rectangle also checks that all fixed circular holes/windows remain inside the source outline, preventing parameter changes from cutting through hardware.

The checker is read-only. It rejects unsupported owner geometry without deleting or repairing it, while retaining undrilled owner copper tracks, copper shapes and silk artwork. Native regressions cover the original reproductions, missing/relayered edges, modified arcs/strokes, embedded cutouts, source dimension shrink and excessive corner radius, valid alternate source radius/thickness, invalid parameters and byte preservation after rejection. Existing diameter/layer checks and artwork ownership regressions remain in place.

Validation is recorded in the PR after a clean guarded baseline and fresh native/aggregate/docs/site checks. No hardware coordinates, generated panel geometry, component identity or qualification claim are intentionally changed. Installed clip/support fit, optical behavior and physical manufacturing qualification remain NOT RUN under their owning tasks.

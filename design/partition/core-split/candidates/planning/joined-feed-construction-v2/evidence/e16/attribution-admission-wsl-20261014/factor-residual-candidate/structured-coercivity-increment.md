The next implemented change uses the same tree as an energy comparison instead
of demanding a componentwise weight. Let S=(A+A.T)/2 for the actual stored
binary64 operator. Exact row sums establish its diagonal-dominance deficits.
A deterministic tree T uses negative symmetric coefficients and one positive
root margin. Independent verification checks the actual coefficients, complete
tree connectivity/order, positive conductances, root budget, context and hashes.
With delta the outward maximum row deficit, S+delta*I-T is SDD, hence

    S >= T-delta*I >= (1-delta*tau) T,
    tau = trace(T^-1) = n/g + sum subtree_size/c.

When gamma=1-delta*tau>0, the trace control bounds the original nonsymmetric
inverse by ceil(sqrt(n))*tau/gamma. A subsequent reviewed refinement uses

    rmax = 1/g + max root-path resistance,
    s = n*n/g + sum subtree_size*subtree_size/c,
    ||A^-1||inf <= sqrt(rmax*s)/gamma.

This follows from coercivity in the T energy norm and the nonnegative inverse
of the grounded tree. It is not a solve of A, a factor residual, or assumed
original element metadata. A trial sqrt must independently pass a finite-positive
check and an outward lower-square test; at most four attempts. Failed refinement
retains the earlier trace certificate and all work; cap failures propagate.

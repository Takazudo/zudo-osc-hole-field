# Historical four-layer model source

These content-addressed Python sources preserve the exact model and prerequisite code used by the P, K and JL diagnostics before the two-layer extension. The manifest maps each historical scope and repository-relative path to retained bytes and SHA-256. Duplicate content is stored once.

This is an audit archive, not the active solver package. Historical numerical matrices and oversized native/mesh artifacts remain ignored local diagnostics; these files do not claim that missing physical inputs or qualifications have been accepted. Historical receipts keep their original digests. Fresh accepted results must be reproducible using the current committed source, source-defined native construction and explicit prerequisite gates. No old receipt is rebound to new implementation bytes.

enabled-layer code does not admit actual EL/O boards until their successful

O-adapter or additional K operator is accepted by this plan.

## Smallest layer/reference extension

1. **Native enabled-layer authority.** Read the pinned board's actual enabled
   copper layer set and compare it with the exact source definition. Export
   only physical enabled foils, including pad/through-hole annuli. A PTH mask
   naming every possible layer must not create phantom inner copper on a
   two-layer board. Retain the raw source/oracle identities and complete
   original pad/drill geometry. Existing four-layer outputs must remain
   physically equivalent; preserve their historical bytes and receipts.
2. **Explicit connected-component reference.** The current native exporter
   assumes a load land exists and indexes `main_rail_members['AGND']`.
   Introduce an explicit source-selected ground contact for EL/O instead.
   Bind reference ref/pad/net/UUID/face/coordinate and transitive native
   component. Keep missing rail feeds visible as prerequisite-only omissions;
   do not mark an arbitrary GH ground as a physical rail main.
   Its cluster loop also indexes `main[net]` for every actual rail. EL has
   genuine GH rail-feed pins but no load lands, so export those contacts and
   foreign copper with an explicit unclassified feed status until a separate
   source feed is declared. Neither a KeyError nor a false physical-main
   assignment is acceptable.
3. **Actual positive foil bands and total depth.** The present numerical
   extractor hardcodes four foil names, B index 3 and total depth 1.6 mm.
   Resolve actual ordered foil names and source-defined bands instead. EL's
   nominal dielectric gap is 0.33 mm; each O adapter's is 1.53 mm. These are
   conditional nominal stack choices, not manufacturing tolerances. Existing
   barrel and sheet-volume foundations already parameterize their band/sheet
   counts; preserve their equations and exact full angular/axial ownership.
   `native_stack.py` currently rejects anything other than four foils and
   three dielectric gaps. Extend its source/native comparison to the exact
   two-foil, one-gap contract. Existing EL/O definitions supply `copper_oz`
   only; introduce explicit conditional thickness and positive z-band rows
   rather than inferring a manufactured stack from those labels.
4. **Empty physical ground foils.** The O source has only B-side GH AGND
   contacts and no selector AGND pin. Native fill may remove an isolated F
   ground island. Represent that genuinely empty ground domain without adding
   phantom copper, an artificial conducting cell or a free interlayer link.
   Preserve physical B-face source/lift orientation even if only one foil
   carries ground. A new stitch is allowed only as a source-defined finite
   geometric/electrical design choice, with its actual holes/access charged.
   This needs a physical-layer-to-active-sheet map: `Sheet` currently rejects
   an empty domain. The foil identity, z band and external source face cannot
   be inferred from the active sheet's numeric index. A zero-barrel board also
   needs neutral empty reductions where correction-energy code currently
   takes an unconditional maximum. The global disconnected-component gate
   stays strict for every sourced/observed component. A genuinely source-free,
   physically separate conductor can be omitted only after its complete
   block separation is established and a constant-potential/zero-current
   extension is retained; no load or wire terminal may disappear with it.
5. **Named finite reference profile.** Let the caller accept an explicit
   source-certified GH reference when there is no main. Retain that profile
   in the sidecar and every ordered matrix transformation. No unnamed gauge
   sink or default K/P reference is allowed. With complete contacts, EL has
   71 independent functions and each O adapter has six.
   Reference identity includes both ref and pad. Remove exactly that one
   function from the header rows, not every ground of the same header. Update
   the caller, cache key, profile/result sidecars and relevant consumers beyond
   the present `mains[0]` expression. A consumer requiring a main reference must
   reject a GH-reference matrix unless it explicitly supports that role.

## Required focused checks before any full dispatch

- A pinned two-layer native fixture proves inactive inner layers are absent
  from exported pad/via/zone geometry, with unchanged real F/B identities.
- A two-foil finite barrel/sheet fixture at both actual total depths checks
  source lifting on F and B, positive gaps, shared normal traces, conservation,
  reciprocal energies and the same upper/lower witness construction.
- An actual B-only ground-domain fixture checks an empty F ground foil and
  the physical B source orientation; a disconnected extra island remains
  disconnected. It must not be repaired by inserting numerical copper.
  Include zero-barrel energy/correction diagnostics and a truly source-free
  disconnected copper component, with rejection if a load/contact is added
  to the omitted component.
- Named GH-reference fixtures reject omitted, wrong-net, wrong-face,
  duplicated or reordered contacts, and verify an explicit reference change
  by energy congruence. Existing four-layer coefficients/functions remain
  unchanged in a focused comparison.
- Each new board needs a fresh successful native prerequisite with complete
  source identities, rules/parity, companion hashes and every declared AGND
  contact connected. A mandatory generic entry gate must reject bare/failed
  exports before extraction and recheck final source/profile hashes.

No global thickness, clearance, source-current or resistance limit changes
are authorized by this extension. Source/generator modifications, native
fixtures and a stable independent review precede serialized numerical work.

## K complete functions

The existing K operator includes only 206 J-facing GH contacts and nine
mains. Extend the source-certified inventory to all 376 GH contacts and all
1903 own-load contacts on the same actual conductor. The complete basis has
2287 functions. First audit actual continuity of the additional 170 GH
contacts, rather than assuming it from J-facing connectivity. Preserve the
old coupling matrix as a historical diagnostic; do not relabel its rows as
the full operator.

`core_model_entry.py` currently rejects `include-loads` and admits exactly
215 selected contacts. Full coverage therefore needs an expanded mandatory
source-admission mode, exact 2288-contact reconciliation and negative omission,
duplicate, face and reference tests. Adding right-hand sides alone cannot
expand the certified native scope.

The source basis can later be reduced only by a proved physical-current or
passive-elimination relation. A typical load estimate, missing profile or
nearby contact does not establish that relation. Before scheduling a full
2287-function calculation, retain an explicit runtime/memory plan and decide
whether exact source-group functions suffice for the stated joined objective.
An added source group must preserve every permitted signed load scenario and
the full candidate endpoint observation, with one global current accounting.

## Physical scope remains open

All these matrices would still be finite numerical-profile diagnostics.
Actual lead/solder/wire contact traces, all permitted terminal distributions,
material/geometry envelopes, current mechanisms and outward network
composition remain necessary for electrical acceptance. No preliminary
operator closes issue 42 or the final EL/O/K routing groups, and no missing
operator is silently replaced by an ideal or zero network.

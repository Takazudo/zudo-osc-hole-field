# Independent board projection coverage

Issue #36 requires the joined per-board native exports to recover the complete physical master and every declared interface. Read-only synthetic S-expression reproductions on main fba004b showed false-success paths: deleting a connector pin node while retaining its component; deleting a physical component from both the assignment and projected board while it remained in the master; and substituting an inserted GH header's value, footprint, MPN and manufacturer while keeping its pins. Review also reproduced a board-only DNP marker change and an assignment-only fitted flag change passing against an unchanged native master. These were checker mutations, not observations of corrupted current hardware sources.

The verifier now compares the complete master component set with the assignment before filtering pins. It excludes only native components accepted by the existing strict AbstractBoundary policy, and requires the partition's declared exclusion list to agree exactly. CN301/XB301 remain requirement-only, footprintless, non-orderable boundaries; no raw/load conductivity is inferred. Physical DNP packages remain part of complete coverage. Native master and projected DNP markers must agree, and the assignment fitted boolean must agree with the master.

For each board, the complete native interface pin map must equal the declaration, including electrical pins, explicit NC positions, unnetted MP pads and each load-wire terminal pin. Missing, extra and changed interface nodes fail before the declared mate graph can establish connectivity. Duplicate or colliding interface references, duplicate board keys and missing board exports cannot collapse the expected set. Native property rows are parsed strictly.

Inserted fitted headers must match the audited GH position/MPN selection, value, MPN/manufacturer properties and generated symbol/footprint identity. A DNP header cannot impersonate the fitted interface. Existing master-part identity checks and the protected custom load-side terminal scope remain unchanged. No circuit, board assignment, fixed centre, interface pin mapping, exact-part evidence or routing changes are made.

Pure regressions cover all three reproductions, absent NC/mechanical/load pins, extra/connected mechanical pins, malformed abstract exclusions, malformed properties, duplicate identities, header substitutions and physical DNP preservation. Fresh native export/regeneration verifies the actual instrument conventions for NC and MP pins. The report records measured interface pin/unconnected counts, verified header identities and validated abstract exclusions alongside the existing physical counts.

Verification receipts are recorded in the PR. The checker proves native export coverage and the declared interface graph; electrical behavior, assembly continuity, physical fit, thermal behavior and fabrication qualification remain NOT RUN. All outputs are unvalidated drafts.

Initial verification: the guarded baseline passed in 398 seconds with no tracked drift. Fifteen focused tests passed. Applying the revised independent verifier to that baseline's actual native exports passed with 5,904 physical packages (5,896 fitted, eight DNP), 20,419 physical pins, 2,646 interface pins, 390 verified fitted header identities, and only CN301/XB301 excluded. The 788 unconnected interface pins are 780 native mechanical-pad nodes plus 8 explicit electrical NC nodes; the 36 load terminals remain connected. Final fresh native export/ERC and aggregate/site receipts are recorded in the PR.

The additional population regressions reject added/removed board DNP markers, master-only changes and mismatched/nonboolean assignment fitted flags while preserving a consistently DNP physical package. Final focused count: 16 tests.

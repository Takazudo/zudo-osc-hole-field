## Implementation revision: full serialization and four-phase runner

The preceding partial-implementation description is superseded on native-context capture and orchestration by this revision; complete warning fixtures remain OPEN. collect.py now saves a fresh native-view artifact, then captures EVERY native-serialized top-level non-copper block as a hash multiset and EVERY supported copper block by occurrence with only its mapped UUID token abstracted. Save is only to a new ignored native-view artifact; source and observed bytes must remain unchanged by collection. Native API behavior remains NOT RUN.

run_protocol.py implements the actual before/after/before_fresh/after_fresh campaign. It requires --execute and an admission JSON naming exact frozen commit, before/after/manifest paths, source context directory, fresh output, explicit finite start_new_phase_budget_seconds and complete sha256 input/producer/context bindings. The original before hash MUST equal the latest adopted K checkpoint and canonical board at runtime. It refuses dirty tracked source or native override. SHA bindings include checkpoint, K definition/netlist/grid, all adapter Python, wrapper/image pin, and full schematic/project/rules/library-table context. Any further external dependency must be added to the admission, not inferred safe.

Each phase folder is a new SIBLING directory under .circuit-cache (exact two-level depth required by retained ${KIPRJMOD}/../../ library paths), never the active chain cache. Each round runs pinned native DRC with refill/save and then the occurrence collector. Three consecutive equal full native serialization/connectivity states are required, within max6 passes. Fresh phases start from copies of each side's settled board. All four final states must agree. Every native command has elapsed time, exit, complete raw stdout/stderr hashes and frozen-source readback before acceptance. Final artifact hashes include phase directories and retained native views. Native warnings are compared before/after and each fresh-copy pair; all results are retained. Runner always reports adopted=false and a checkpoint-only status. Native command failures preserve raw output; future process cancellation ownership belongs to the explicitly admitted parent job.

Ten lightweight software tests now pass, including full serialized context/copper-flag mutation detection, missing phase/short convergence/unstable passes and changed fresh-copy native context. They are NOT native execution evidence.

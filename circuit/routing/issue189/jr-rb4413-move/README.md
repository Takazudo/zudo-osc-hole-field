The proposal retains all old copper and adds six full-width segments and one 0.6/0.3mm via. RB4413 is not fixed or in a bypass cluster; orientation and side remain unchanged. Plan/proposal/source hashes bind the experiment.

`pilot.py` runs only with pinned KiCad10.0.6. It checks the settled baseline, moves only RB4413 in a disposable copy, applies the exact reviewed copper and checks settled/fresh native DRC, parity, warnings and all original pad memberships. Canonical board and source floorplan hashes must remain unchanged. No publication path exists. A positive gate remains provisional until independent full-block retention and physical-delta reconciliation plus deterministic source regeneration pass. The source floorplan is generated by scripts/checks/partition35_floorplan.py; do not hand-edit its generated JSON for adoption.

Worker execution uses the existing read-only local-pilot job on an isolated immutable worker branch. No core worker is changed or duplicated. Source regeneration/native placement checks remain NOT RUN until explicitly recorded.

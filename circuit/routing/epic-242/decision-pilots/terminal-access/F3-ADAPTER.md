# F3 exact-access proposal method

This opt-in adapter exercises the saved F3 terminal-access witnesses on K1402
and two-A. It does not change the shared grid router or any physical input.
The method is source reviewed, not admitted for native execution. The reviewed
packet will pin this method's commit separately from its packaging commit.

## Search contract

- Retain all four original F3 demands, in order: positive supply, negative
  supply, return, signal. Preserve complete native groups as obligations.
- Use the same deterministic union of the retained first three straight and
  first three edge-plus-via witnesses per anchor from K1402 and two-A. Recheck
  nanometer-rounded geometry on each physical board and earlier whole proposals.
- Validate full-width terminal contact, swept segments, the rounding bridge and
  all-layer via geometry. A saved via hands off to In2.Cu; a straight witness
  stays on its original layer. Named anchors remain the only terminal identities.
- Feed verified lattice landings as private, single-layer search markers into
  the unchanged router. Original physical obstacles remain present. Search from
  the second original anchor toward the first; reject landing-count inversion
  instead of letting the router reverse this direction. No retry or alternate
  demand substitution is allowed.
- Stitch complete source/grid/destination chains. Reject unexplained through
  flags, discontinuous layer changes, paths outside the shared bounds, collisions,
  new-via spacing violations, UUID aliases and disconnected emitted rows.
- Replay cumulative fill preservation from the original physical baseline with
  full segment capsules and via disks on every guarded layer, including a check
  against total disappearance. Any rejection discards the entire pair's copper.

The frozen 0.1 mm raster, 50,000 expansions/search, 6 mm window, 0.5 mm rail and
0.3 mm signal widths, 0.25 mm clearance, 0.6/0.3 mm vias, shared bounds and all
original obstacles are unchanged. There are no cuts, rip-up, fallback or plane
shortcuts. Virtual search markers are never emitted as physical pads.

## Input and execution boundary

`f3_fixture.py` recovers untouched before/context bytes from complete,
SHA-authenticated route1420/1438 artifacts. It authenticates the original method
29140d4, original boards/dumps, full native groups and preserved cohort evidence,
then seals the new committed adapter and dependencies. Fixture preparation only
computes exact landing geometry; it never routes a saved board.

`route_f3_access.py` refuses missing admission before numerical imports. The
caller must supply the reviewed fixture-lock SHA literally. Validation checks
the committed method, exact before/context census and every locked file before
and after search. Only proposal and diagnostic JSON are written. The existing
resource guard and timeguards remain mandatory; environment variables alone do
not constitute owner admission.

Every output keeps `accepted`, `adopted`, `native_exact_pair_closed` and
`coupled_connectivity_success` false. Geometric continuity is not native closure.
Signal-only improvement is not complete cohort or architecture success. A legal
escape on one board and an exact negative on the other can be informative;
neither both-board success nor a new via at both endpoints is required.
Center-inside contact and the saved finite straight-witness family are diagnostic
assumptions, not physical impossibility claims. Native application, settlement,
fresh connectivity/full-warning/preservation gates need separate reviewed scope.

## Source validation

The terminal-access suite contains 35 source tests, including a synthetic route
through the unchanged Python A* implementation with native A* forbidden. It
covers collision ownership, terminal continuity, via spacing, cumulative fill,
direction depletion, bounded chains, UUID aliases and fixture authentication.
Two independent source reviewers found no remaining blocking issue. Source
checks also passed `pnpm circuit:check`, `pnpm check` and the baseline verifier:
1,881 frozen inputs, two reviewed tooling replacements, 195 harnesses and 390
complete endpoint/pin-map/pose records preserved. The accepted 117/129/1402 and
DRC/parity 0/0 receipts are inherited evidence, not new native measurements.

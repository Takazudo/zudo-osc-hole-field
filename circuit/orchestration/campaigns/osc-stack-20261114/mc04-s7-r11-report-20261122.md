**Rules (`links_gate.stable_clusters`, used by `place_gate`):**
- Every baseline cluster keeps its ID and its remaining members. A cluster with no members left is retired, and its
  ID is never reused.
- Only pairs that no baseline cluster holds are clustered. Each one, taken in ID order, joins the nearest kept
  cluster when two conditions hold:
  - the cluster's running centroid lies within the 35 mm join radius;
  - the circuits still fit.
- Any pair left over goes through the existing greedy clustering and is numbered after the highest baseline ID.
- The order is deterministic.

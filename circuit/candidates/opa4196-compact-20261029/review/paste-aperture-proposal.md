# Proposal: U110/U210 paste aperture trimmed to the TI example length

**PROPOSAL ONLY. Not adopted.** No footprint, board, stencil or fabrication file was
changed or produced. This proposal needs an owner decision and an assembler review.

## Proposed apertures

| Item | Value |
| --- | --- |
| Copper pad | unchanged: 1.95 × 0.60 mm, inherited `SOIC-14_3.9x8.7mm_P1.27mm` (`d686d259…2337`) |
| Paste aperture | 1.55 × 0.60 mm, R 0.05 mm, aligned to the pad's outer (toe) edge |
| Aperture x span | 1.90–3.45 mm from the package centre on each side (copper 1.50–3.45 mm) |
| Paste area / volume per lead | 0.928 mm² / 0.116 mm³ at 0.125 mm foil (1:1 aperture: 1.151 mm² / 0.144 mm³) |
| Area ratio at 0.125 mm | 1.73 |
| Basis | `fact-op-audio-land-pattern-example` (TI D0014A, PDF index 40–41): example pad and stencil 1.55 × 0.60 mm |

The exact 14 aperture centres are in `paste-aperture-proposal.json`, generated by
`paste_proposal.py`.

## Effect

- The trim removes the 0.40–0.50 mm of paste that sits under the package body. That
  paste is the bead/ball risk named in this review's land assessment.
- Toe and heel copper coverage stay as they are; only the deposited volume and its
  position change.
- The deposit matches TI's example volume. Its outer edge is 0.025 mm further inward
  than TI's, because the project pad ends at 3.45 mm.

## How it would be implemented (not done)

- KiCad's `solder_paste_margin` shrinks all four sides equally. A −0.2 mm margin would
  leave a 1.55 × 0.20 mm slot, which is too narrow, so the margin cannot produce this
  aperture.
- The implementation needs a separate footprint variant. In that variant each numbered
  pad keeps `F.Cu F.Mask` without `F.Paste`, plus an unnumbered smd pad on `F.Paste`
  only at the aperture centre.
- The variant must be assigned only to U110/U210, because the inherited footprint is
  shared by 347 SOIC-14 package rows in each variant. Applying it to all users is a
  separate scope question.
- The assembler may still change apertures: the JLC stencil standard is retained in
  stage24 and permits aperture optimization. The proposal is therefore an input to
  assembler review, not a guarantee.

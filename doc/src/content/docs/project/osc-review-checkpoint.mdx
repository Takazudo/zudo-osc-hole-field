housings, 1,822 fitted crimps and 18 additional main power/return wires. It allocates
650 fitted IC packages and 5,896 fitted master components before interface
hardware. These are source counts, not a priced or accepted factory order.

The board planes and boundaries serve different purposes:

| Board group | Proposed component-face z | What drives the proposal; what remains negotiable |
| --- | ---: | --- |
| JL / JR | −10 mm | Fixed jack centres and proposed bushing/shoulder seating; two boards address the rejected single-J routing allocation. Actual seated datum remains unqualified. |
| P | −11.8 mm | Shared pot/toggle/button plane and custom body/plunger support. Hardware reach needs a coupon; the panel centres alone do not prove this depth. |

The generated connector packing assigns the 195 harnesses as follows. Each count
is a physical cable assembly, not a count of independent signals:

| Boundary | Harnesses | Architectural purpose and review opportunity |

These boundaries implement the current partition; they are not all unavoidable
consequences of the feature set. Consolidation would change circuit ownership,
net cuts, routing density and electrical/thermal budgets, so no reduction is
counted before a source-defined alternative demonstrates those obligations.

The fixed panel grid does not itself require a core plane at −100 mm. The current
loom construction helps explain that allocation. From
`scripts/checks/partition35_loom.py`, the 4 mm bowed GH path has the checked radius
bound `span² / (8π²)`. Requiring at least 9.398 mm gives a 27.240344 mm span.
With the selected rear-selector board and connector datums, this requires the K
face at least 72.440344 mm behind the panel for that path family.

The main power path uses the bound
`span² / (2π² × hypot(10, bow_x))`, with a 25.908 mm bend-radius requirement.
The resulting minimum K face depths for the current path family are:

| Branch | Necessary K depth for the existing bend screen |
| --- | ---: |
| JL | 94.526877 mm |
| JR | 85.112476 mm |
| P | 86.912476 mm |

Values are rounded upward. These are necessary screens for the existing proposed
paths, not physical minimum depths or a complete collision/assembly proof. They
explain why simply moving K to the earlier 24 mm study plane fails the present
routing construction. A shallower design needs new wire paths, exit orientations
or board interfaces, followed by renewed fit, electrical and service checks.

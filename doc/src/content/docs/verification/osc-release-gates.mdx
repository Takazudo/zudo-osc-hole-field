## Selected first review scope

Owner decision E20 selects an **externally assembled engineering prototype** for the first manufacturing review ([confirmation](https://github.com/Takazudo/zudo-osc-hole-field/issues/315#issuecomment-6748038705)). Specimen-dependent selector installed-fit (#55) and optical/thermal (#64) tests are first-article obligations after fabrication. This settles their timing, not their result or acceptance limits. All physical tests remain **NOT RUN**: no specimens, populated instrument or authorized test setup exist in this implementation session.

E18 authorizes regional placement development, not adoption; D4233 remains provisional. E19 requires indoor, non-condensing operation at 0–40°C ambient. Installed component/case/junction temperatures require separate evidence, and the existing pitch calibration/accuracy scope at 25°C is unchanged. Preserve all 438 fixed hardware centres and all 33 independently patched module instances.

## Before energization

#57 retains actual source evaluation, as-built source/population identity, programming/readback and safe initial-power safeguards before connecting the instrument or applying an unsafe charger. The historical P+B current-limited 5 V / B-disconnected / 5 V-and-15 V-only programming precondition remains applicable to that historical hardware; it is not a programming prescription for an unbuilt revised E11 source. The revised source needs its own verified configuration and bring-up procedure. No energization is authorized here.

Protection, isolation and sequencing implementation must already be justified before ordering; post-build tests verify the built realization. Follow the staged first-power procedure so unverified startup/fault behavior is tested with appropriate safeguards before unrestricted operation. Do not move a prerequisite source or programming check after the operation it protects.

## Review and release boundary

Distinguish implementation complete, required pre-order evidence complete, manufacturing package ready for owner review, and physical/production qualification. None is established merely by this scope decision or green draft CI. The parent implementation tracker and physical issues remain open until their own acceptance is met.

Preparing a reviewable package is authorized after its prerequisites pass. No current file is declared order-ready by this page. Generate outputs only from the exact checked native revision and retain inspection, reproducibility and review evidence. No purchase, quote, supplier contact, manufacturing upload/order, energization, release publication or documentation deployment is authorized. Do not upload historical prototype exports.

## Labels and source ownership

The authored `design/service/trimmer-functions.json` contains 100 unique rows and
28 explicit Role definitions. Join a row by **existing Ref + Block + Role**.
The label contains the short English module and function, and `reference_label`
retains the Ref. A label such as **OSC1 SINE LEVEL / RVO1111** must never become
SINE SHAPE. RV1601 is **ALL OSC OCT SPAN**, not an individual oscillator trim.
RVO references and blank-MPN trims are included by footprint/symbol recognition;
prefix-only or nonempty-MPN filtering omits required parts.

The function dictionary contains no XY, rotation, face or board assignment.
`scripts/service/build_trimmer_inventory.py` joins source parts via `designator()`
to the retained core netlist, PCB footprints/pads and current source floorplan.
Its generated `design/service/trimmer-inventory.json` records 44 F.Cu and 56 B.Cu
trimmers, complete pins and source/native poses. Source XY uses the source frame;
native XY includes the existing +100/+50 mm translation in `scripts/pcbgen/place.py`.
Orientations are normalized modulo 360 for comparison; raw native orientation is
also retained. Pin tokens use the existing board projection `net_token()` mapping.
These consistency checks read saved KiCad files; they do not run native KiCad.

For the annotation lane, `label` is the functional text and `reference_label` is
retained visibly alongside it. Placement comes from the current inventory and
must be refreshed against an assigned integration input. Unknown roles, missing
rows, duplicate Refs, MPN loss, changed pads or poses fail explicitly. A new trim
requires a reviewed contract update; no automatic label from a guessed Role.
All `rotation_direction` values are **UNKNOWN / NEEDS BENCH**. Manufacturer
CCW/wiper/CW terminal identities do not establish a frequency/time/gain arrow,
especially after back-face installation. No direction arrow is authorized here.

## Component identity review

The 77 source-assigned identities remain unchanged: 21 Bourns TC33X-2-102E and
56 TC33X-2-103E. Presence of an MPN is not qualification. The 23 remaining source
MPNs stay blank: five 20 kΩ HF trims, fifteen 50 kΩ base trims and three 500 kΩ
resonance trims. Every gap is individually reviewed in

source locks, exact supplier observations and unresolved qualification.

Same-value **options only** are TC33X-2-203E, TC33X-2-503E and TC33X-2-504E.
[Bourns TC33 rev.08/19](https://www.bourns.com/docs/product-datasheets/tc33.pdf)
is retained at `circuit/sources/ic-library/TC33X.pdf`, SHA-256
`b13258ee9f777b70198554ad4ed43cab2167b2bdf31bdcbe52c4956bfff1adbf`.
Physical PDF index 1, Standard Resistance Table and How To Order support the
values, rotational-stop `-2` variant and E reel. Index 0, right-hand TC33X-2
Product Dimensions supports the 3.6 × 3.8 × 1.2 mm terminal-inclusive nominal
body and general ±0.3 mm tolerance. The corresponding conservative independent
axis bounds are 3.9 × 4.1 × 1.5 mm; these exclude tool, hand and cable access.
The existing footprint courtyard is provisional and requires installed fit review.
No larger package or different resistance is silently substituted.

The primary ±25% total-resistance tolerance gives 15–25 kΩ, 37.5–62.5 kΩ and
375–625 kΩ ranges. The 2% endpoint-resistance bound for values above 1 kΩ means
zero-ohm adjustment is not guaranteed. These limits require calibration-range
analysis of the unchanged surrounding networks, not just an order-code match.
Supplier raw-page acquisition was blocked; stock, factory allocation and assembly
acceptance remain unknown. `COMPONENT_REVIEW_READY` means all 23 risks have
reviewed dispositions; it does not select the candidates or close production gaps.
Source-integration and exact-component owners decide any adoption separately.

## Proposed calibration sequence

All targets below describe source intent and remain **NEEDS BENCH**. Record the
actual populated revision, component identities, rail conditions, warm-up,
ambient/temperature range, instruments, load/bandwidth, knob/CV settings and
raw observations before assigning a measured result. Numeric test tolerances and
qualified ranges must be agreed by the circuit/bench owners, never invented from
these labels. This page does not authorize energization.

First qualify references and loaded shared octave span. Then characterize each
oscillator base pitch, temperature compensation, V/OCT and HF tracking together;
repeat interacting settings before symmetry and final sine level. Check filter
base frequency and slope before maximum resonance, then each OTA balance under
specified controls. Characterize both AR time-current paths with the selected
thresholds, independently checking scale, base timing and offset. Set MIX4 gain
and balance across a control sweep; check wavefolder offset and drive ceiling.
Measure noise levels over a defined bandwidth/load without treating gain trims
as spectral corrections. Mechanical lane #246 and assembly lane #258 must verify
access to every F.Cu/B.Cu adjustment in the actual stack, with harnesses present.

## Useful optional provisions

The selected AS3340D source already provides distinct BASE PITCH (pin 15 summing
feed), TEMP COMP (Scale1 pin 1 RZ), V/OCT (Scale pin 14 Rs) and HF TRACK (pin 7)
adjustments. RZ covers temperature-compensation current matching; an extra RT
trim is not justified until measured existing range fails.

An independent **pin 13 linear-reference/current trim** is an explicit option,
not a circuit change. Current `oscillator.py` fixes a 1.2 MΩ feed from +12 V to
LINEAR_REF; BASE_TRIM does not independently set that current. The retained
ALFA [AS3340/AS3345 v7 primary source](https://www.alfatriode.lv/eng/sc/AS3340.pdf)
at `circuit/sources/ic-library/AS3340.pdf`, SHA-256
`66108a3ddcc78a158d66974a497801ce6a429d465b338f6c8d656fd7ddce815e`,
physical index 0/printed page 1 General Description and index 1/printed page 2
AS3340 connection diagram separate Scale1/Scale2 compensation current, Scale
and RR/pin 13 reference functions. This supports investigating an independent
current setting; it does not prove an improvement or supply stability.

A concrete option study would add one bounded trim plus fixed limiting/feed
resistance per oscillator (five trims total), or a separately qualified local
reference/feed network. Value, range, package, load and exact topology are **NOT
SELECTED**. The architecture owner must reserve five additional component
courtyards plus tool access, account for reference/buffer load and sensitive
locality, and compare pitch/HF/temperature/supply behavior before selection.
No zero-area or invented 1 kΩ/10 kΩ reservation is implied. Pin 9 guidance for
AS3340A must not be copied to the selected AS3340D SOFT-sync connection.
Broader component/circuit work remains with #21/#29/#30/#31; source, protection
and physical gates remain open.

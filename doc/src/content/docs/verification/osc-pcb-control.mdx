The shared control board has a reproducible **unvalidated, unrouted layout candidate** at `boards/osc-control/osc-control-layout.kicad_pcb`. Its 418 source packages and 36 supports preserve all 139 fixed control positions. The two complete slew circuits sit beside their unchanged potentiometers; all four amplifier bypass capacitors are 2.2975 mm from their supply pads.

The candidate uses the reviewed local edge tab beside RV601 and separate reservations around the six power terminals. It remains separate from the canonical partition outline. The tab and neighboring octave adapter pass their conditional source-envelope screen; installed fit remains unqualified.

| Current native check | Result |
| --- | --- |
| DRC violations, including silkscreen | 0 |
| Schematic parity findings | 0 |
| Visible references | 418, using 1 mm text |
| Complete native open-edge count | **872** |
| Multi-pad candidate nets | 348 |
| Routing / physical qualification | **Incomplete / NOT RUN** |

The source-controlled references avoid same-face component courtyards, pad projections, other silk and board edges. Fresh CI replay regenerates the candidate and checks complete PCB, project, schematic and custom-rule bytes before running native DRC. It also rejects a missing reference, a nonfinite position, a label over a component and a changed bare input. Reference placement preserves every other PCB byte.

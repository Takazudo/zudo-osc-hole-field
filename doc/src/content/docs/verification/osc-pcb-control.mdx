The shared control board now has a reproducible **partially routed, unvalidated candidate** at `boards/osc-control/osc-control-routed-draft.kicad_pcb`. Its 418 source packages and 36 supports preserve all 139 fixed control positions. The two complete slew circuits remain beside their unchanged potentiometers; all four amplifier bypass capacitors are 2.2975 mm from their supply pads.

The candidate uses the reviewed local edge tab beside RV601 and separate reservations around the six power terminals. It remains separate from the canonical partition outline. The tab and neighboring octave adapter pass their conditional source-envelope screen; installed fit remains unqualified.

| Current native check | Result |
| --- | --- |
| DRC violations, including silkscreen | **0** |
| Schematic parity findings | **0** |
| Source track segments / through vias | 1,345 / 368 |
| Connected source ground contacts | **344 / 344** |
| Complete native open-edge count | **376** |
| Independent reload and refill | Same ground and open-edge counts |
| Routing / electrical and physical qualification | **Incomplete / NOT RUN** |

The unrouted placement reference remains at `boards/osc-control/osc-control-layout.kicad_pcb`, with 872 open edges. Adding the original ground prerequisite reduced that to 529. The current explicit copper and local repairs reduce it to 376; the full per-net inventory is retained in `design/partition/control-copper/ratsnest.json`.

Fresh refill exposed four ground islands hidden by the first recovered autorouter fill. Four short front-layer signal bridges now open those back-plane boundaries, and a separate via joins an unfinished signal-layer transition. The replay checks every source ground contact after a fresh load and a second refill. It preserves the original footprint, outline and reservation bytes. A passing DRC alone is not treated as connected or electrically compliant copper.

## Remaining work

- With rail copper ≤1 mΩ and total common AGND copper ≤0.5 mΩ,
  rail-plus-one-return losses are **15.321 / 15.058 / 11.113 mV**.
- Residual to 20 mV is **4.679 / 4.942 / 8.887 mV**. One return wire and its

  **30.642 / 30.116 / 22.226 mV**, a **deterministic violation** of 20 mV.

### One joined budget, including missing returns

`joined/check.py` builds an explicit conditional return network for each of the
five mechanical alternatives: **380 individual GH AGND conductors**, plus
12 dedicated main returns for two cores or 15 for three. The four JL–P utility
harnesses, EL and all octave boards are included. It removes every individual
main return, each same-branch pair, and each complete three-return branch,
then solves the changed network. No patch-sleeve path is credited.

For a candidate GH conductor, remove it, set other wire/contact resistances to
their admitted maxima, and solve the one-ampere effective resistance `Ralt`.
With its own cold cable lower resistance `Rmin`, the upper current is:

```text
Ibound = 4.6 A × Ralt / (Rmin + Ralt)
```

The balanced signed-injection class has total positive and negative magnitudes
each at most 4.6 A; opposite rail currents are not cancelled and equal sharing
is not assumed. Reciprocity and the passive-network maximum principle bound
transfer voltage; Rayleigh monotonicity bounds the alternative resistance.
A disconnected alternative gives the full current bound, never zero. The
solver rejects invalid resistances and checks its Kirchhoff residual.

GH cable lower resistance is the particular alternative's sampled centreline
length times 0.1 Ω/m. Its hot alternative uses admitted cut length times
0.17 Ω/m plus the inherited 0.1 Ω two-end contact/crimp allowance. These are
assembled acceptance conditions; the cold minimum is not a manufacturer
minimum. Main branches use Alpha Wire **5859 BK005**, at the unchanged
0.013 Ω/m hot requirement, ≤110 mm cut and 0.2 mΩ combined terminations.
GH loom identity remains Alpha Wire **6821 BK005** and the existing JST
header/housing/contact variants. Source hashes bind the retained primary PDFs.

The lumped board nodes are **not native connected components**. The screen adds
one 0.5 mΩ bound for the **sum of all omitted copper/access resistance maxima**
to wire-only `Ralt`. This is a stronger sufficient condition than the original
path budget, not a measured allocation or a new allowance per board. Every
collapsed terminal group must actually be connected and admit the lifted flow;
isolated same-net zones cannot satisfy it. Unknown EL/octave accesses are not
assumed physically zero. Actual extraction/equivalence remains blocked.

source boundary is invented. Direct star branches retain the original scalar
screen. If a proposal actually introduces two serial sections, both wires and
both termination pairs must be charged, with copper charged only once:

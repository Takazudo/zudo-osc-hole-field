This section records the R21 module responsibilities, interface assumptions, placement authority, and proposed board structure. The [architecture overview](./overview.mdx) summarizes the instrument's functional blocks and open boundaries. Module pages describe the intended behavior and work required before circuit capture; they are not complete schematic designs.

[Grid and artifact authority](./osc-grid-authority.mdx) identifies the fixed coordinate source, while [board partition and panel stack](./osc-board-stack.mdx) records mechanical assumptions that still need evidence. Exact component claims belong in the evidence records.

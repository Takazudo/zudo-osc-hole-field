# Source-file availability

The component register contains working source URLs checked through the browsing tool and explicitly marked inherited references. Direct PDF downloads into this runtime failed because outbound DNS was unavailable. **No vendor PDF or 3D CAD file is claimed to have been downloaded in this revision.** `parts/source-downloads.json` records those failures, not successes.

The PDFs under `panels/` are generated panel-size proofs, not manufacturer datasheets. Use the source links in `parts/components.json` to obtain current manufacturer documents locally before schematic capture. The retry script reports failures rather than silently accepting HTML as a PDF.

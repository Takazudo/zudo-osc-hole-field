## Correct file ownership

Authored project intent, architecture, research, decisions and verification are supplied in this overlay. `doc/src/content/docs/components/**`, `circuit/generated/preflight.json`, and `doc/public/assets/component-previews/**` belong to the generator and are deliberately absent from the payload. The existing R20 handcrafted component pages are not installed there.

The workbench and pictures are ordinary reviewed public assets. The installer appends their exact paths to `circuit/publication/assets.json`, preserving existing entries. No upstream package, version pin, workflow or evidence schema is overwritten.

## Promote evidence, not appearances

Create exact owner bundles with `pnpm exec zudo-circuit-doc new-component <suffix>`. Complete manifest, sources, facts, coverage, routing, interactions, pin-map and SKILL, then inventory, direct routing, selection and count locks. The manual inventory's declared placements are not a binding to a schematic.

Keep six native verdicts distinct. A downloaded distributor listing confirms order identity, not manufacturer performance. A source URL without bytes is unavailable. Use the runtime's zero-hash sentinel only inside a genuinely unavailable source record; do not create a made-up digest. Original files must be downloaded/hash-locked locally before primary PASS promotion.

## Commands after import

```sh
pnpm circuit:doctor
pnpm circuit:check
pnpm circuit:generate
pnpm check
pnpm build
pnpm check:site
pnpm dev
```

The build should remain offline after dependency installation. Online evidence acquisition is a separate explicit operation. Exit 4 for a missing optional tool is NOT RUN, not PASS. Report the exact check scope and current source revision.

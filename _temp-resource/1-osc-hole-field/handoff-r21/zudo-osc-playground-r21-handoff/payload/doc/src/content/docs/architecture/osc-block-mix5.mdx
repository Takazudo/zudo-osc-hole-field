## Functional contract

Five independent bipolar attenuverters feeding a mono sum, then manual LEVEL.

## Work before schematic lock

Resolve gain normalization/headroom; not automatically divide by five. Indicator at each input and SUM; clip must reflect internal overload, not only attenuated output.

All corresponding port/control cells are in the canonical grid. Read the generated per-instance entries in `project/osc-playground/block-contracts.json`; do not infer pinout or voltages from those visual labels.

## Deliverable

A reviewed one-channel schematic, explicit signal/CV ranges, chosen exact parts and pin maps, corner calculations, simulation/bench plan, power budget and factory test procedure. Replication count follows the current spec, not historical panel versions. Never patch independent blocks internally just to simplify testing; use external test cables or clearly temporary fixtures.
